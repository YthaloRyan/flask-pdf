🧾 Projeto Flask – Geração de PDF para Registro de Vendas

Projeto freelance desenvolvido em Flask, com o objetivo de criar um sistema web simples capaz de registrar informações de uma venda e gerar automaticamente um PDF contendo todos os dados fornecidos. O foco do projeto é agilizar processos internos, permitindo que o usuário preencha os dados no site e receba imediatamente um documento formatado e pronto para uso.
